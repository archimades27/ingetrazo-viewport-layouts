# Viewport Layouts for IngeTrazo

Arrange the model in a single viewport, a horizontal or vertical split, or four synchronized views. Drag the dividers to resize panes. Use the button in a pane header to maximize the pane and restore its previous layout.

## Install

Open **Extensions → Open plugins folder** in IngeTrazo, copy `multi_viewport.py` into that folder, and restart the app.

Tested with IngeTrazo 0.6.0 on Windows. The extension uses internal viewport APIs that may change between IngeTrazo versions.
